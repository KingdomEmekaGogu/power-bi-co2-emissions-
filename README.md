# 🌍 CO2 Emissions Analysis Dashboard  

**Tools Used**: Power BI, Excel (Data Cleaning), Kaggle Dataset.  
**Dataset**: [CO2 Emissions by Country](https://kaggle.com)

## 📊 Project Overview  
This Power BI dashboard analyzes **CO2 emissions trends across countries and years**, answering key questions:  

1. **How have CO2 emissions changed over time by country?**  
   - Line charts showing emissions trends (1990–2023).  
2. **Which countries improved/worsened the most?**  
   - Rankings (highest reduction/increase in % or absolute terms).  
3. **How do countries compare in per capita emissions?**  
   - Map/bar chart with emissions per person.  
4. **How does emissions density vary geographically?**  
   - Heatmap or region-wise breakdown.  
5. **Is there a correlation between population/density and emissions?**  
   - Scatter plot with regression analysis.  

## 🛠️ Data Pipeline  
1. **Source**: Kaggle dataset (raw data).  
2. **Cleaning**:  
   - Removed missing values in Excel.  
   - Standardized country names (e.g., "USA" → "United States").
   - Removed Blank Spaces and Hyphens in Calling Code
3. **Power BI**:  
   - Created calculated columns (e.g., emissions per capita).  
   - Designed interactive visuals (slicers, tooltips).
